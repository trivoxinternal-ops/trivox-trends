## 3. AI Voice Agents

### 🆕 What's NEW (Last 7 Days)

- **ElevenLabs — September 21, 2026 changelog (largest single-day release this year):**
  - **Parallel tool calls** — agents can now execute multiple tools in a single turn (`enable_parallel_tool_calls`, default true); significantly reduces round-trip time for multi-step workflows
  - **GPT-6 Astra natively supported** as an agent LLM option — the most capable OpenAI model now available inside ElevenLabs agent config
  - **Slack alerting** for agents — monitoring alerts now route to Slack channels alongside PagerDuty and webhooks; enterprise ops teams can get voice agent alerts in existing Slack channels without new tooling
